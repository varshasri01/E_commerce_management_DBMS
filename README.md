# E-Commerce Management System

## 📌 Project Overview

The E-Commerce Management System is a DBMS mini project developed using MySQL. It manages essential e-commerce operations, including customers, products, categories, suppliers, and sales information.

## 🎯 Objectives

* Store and manage e-commerce data efficiently.
* Maintain relationships between database tables.
* Retrieve useful information using SQL queries.
* Analyze sales, customer purchases, and product stock levels.

## 🛠️ Technologies Used

* MySQL
* MySQL Workbench
* SQL

## ✨ Key Features

* Customer and product management
* Category and supplier management
* Best-selling product identification
* Identification of customers with the highest purchases
* Low-stock product detection
* Category-wise sales analysis
* Monthly revenue analysis

## 📂 Project Contents

* `ER diagram/` – Entity Relationship Diagram
* `screenshots/` – Screenshots of SQL query execution
* `sql/` – SQL scripts for database creation, sample data, and queries

## 📚 Learning Outcomes

* Database design and ER modelling
* Primary keys and foreign keys
* SQL queries and data retrieval
* Relational database management
* Basic sales and inventory analysis

DBMS Mini Project
